Boston Crime Forcasting

Technologies Used: Streamlit, Prophet, Contextily, GeoPandas

Engineered an interactive Streamlit dashboard for comprehensive Boston crime analysis and forecasting, utilizing Python libraries such as Pandas, GeoPandas, Plotly, and Matplotlib to preprocess data, perform geospatial clustering with DBSCAN, and visualize crime hotspots effectively.

Implemented advanced predictive modeling using Prophet for time-series forecasting of crime trends, integrated geospatial data visualization with Contextily and Plotly Express, and optimized resource allocation by identifying top crime clusters and providing actionable insights for law enforcement agencies.

Multimodal Skin Cancer Detection

Technologies Used:Keras, TensorFlow

ETrained a ResNet50 and LightGBM model on the ISIC skin lesion dataset through Keras that achieved an accuracy of 97.65% and a binary log loss of 0.0747.

Utilized stratified KFold and robust feature engineering of the tabular features for training.
